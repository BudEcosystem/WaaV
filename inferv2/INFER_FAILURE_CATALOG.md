Accumulating evidence for the brutal-critique + TDD-plan round. Each entry: failure → root cause → mitigation (cited) → WaaV adoption.

## A. vLLM-Omni `add-tts-model/SKILL.md` (distilled production rules — the 5 cross-cutting invariants)

**I1 — Streaming output contract (delta vs cumulative).** FAILURE: "Cumulative-vs-delta mismatch is the MOST COMMON silent bug — offline RTF passes, but users hear replays or truncation." Cumulative re-decode from step 0 = O(N²). ROOT: per-step `forward()` semantics undocumented + consolidation path skips the modality key → offline consumer gets only the final chunk. MITIGATION: pick delta (yield only new samples), document in docstring, audit emit→consolidate→consume chain end-to-end (`_consolidate_multimodal_tensors` must concat the audio key, not `continue`). WAAV: the streaming egress (M3) MUST be delta-only; the WS frame contract already carries `ChunkMeta`; add an explicit invariant test that offline-concatenation == streamed-concatenation byte-for-byte.

**I2 — Multimodal consumer hygiene.** FAILURE: `RuntimeError: Boolean value of Tensor with more than one value is ambiguous`. ROOT: `dict.get("a") or dict.get("b")` evaluates a tensor's truthiness. MITIGATION: explicit `if x is None` chains; defensively handle list form (`torch.cat([t.reshape(-1)...])`); assert shape/dtype/duration, never truthiness for presence. WAAV: Rust is typed so this exact bug can't occur, but the lesson = the egress payload can be Tensor | list[Tensor] | ndarray | scalar; the sidecar IPC contract must pin ONE shape and assert it.

**I3 — Hot-loop GPU discipline (the "2400 syncs/request" rule).** FAILURE: per-step `.item()`/`.cpu()`/`.tolist()` = a GPU→CPU sync; "10 steps × 60 frames × 4 ops = 2400 syncs per request" → latency collapse. ROOT: Python control flow on tensor values. MITIGATION: no `.item()/.cpu()/.tolist()` in any per-step loop (AR decode, diffusion solver, CFM Euler, vocoder block loop); `dst.copy_(src)` not `dst.fill_(src.item())`; `torch.where`/masking instead of Python branches; `torch.compile(forward, fullgraph=False)` on the whole forward. WAAV: this is the single most important Path-B sidecar rule — the torch runner's per-frame loop must be sync-free; add a test that asserts zero D2H syncs via a CUDA-event/profiler guard during a decode.

**I4 — Validation pyramid (offline RTF is necessary but NOT sufficient).** FAILURE: "Declaring a model done without all three has shipped regressions more than once." MITIGATION: 3 layers — (1) offline RTF/duration, (2) browser streaming playback (catches delta/cumulative + chunk-boundary glitches + TTFP), (3) concurrent requests `max_num_seqs>1` with 4+ parallel (catches per-request state leaks + codec-window round-robin gaps). WAAV: the accuracy gate (§5.2) must add a STREAMING-playback check + a CONCURRENT-request check, not just offline parity. The current native-parity bar is layer (1) only.

**I5 — Per-request state owned by the request, not the model.** FAILURE: "A shared buffer silently corrupts audio across concurrent requests — symptom is crosstalk or truncation only under load." ROOT: model caches streaming generators / codec buffers / sliding-window pads / CUDA-graph state across `forward()` without keying by request. MITIGATION: `self._state: dict[req_id, State]`, free on finish. WAAV: the lockstep scheduler's per-slot state IS this discipline; but the Path-B sidecar (which holds Python codec/sliding-window state) must key by slot-id and free on slot-reset — add a concurrent-crosstalk test.

**Phase-2 "audio wrong" debugging priority (ordered by experience):** RoPE/attention mask → RMSNorm epsilon/placement → hop length (product of upsample rates) → token-ID offset from vocab base → sampling params → codebook-major vs frame-major layout → dtype (**float32 for codec decoders; autocast corrupts audio**). WAAV: this is the model-onboarding checklist; codec stays fp32 confirmed again.

**Critical params table (impact if wrong):** hop length → wrong duration/streaming noise; token-ID mapping → garbage codes/noise; codebook count/size → shape-mismatch crash; stop token → never-stops or stops-early; dtype/autocast → silent quality degradation; repetition penalty → must match reference (often **1.0 for TTS**).

**Codec stage `max_num_seqs`:** Stage-0 (AR) needs `≥4` to pipeline; Stage-1 (codec) intentionally `1`; "Default of 1 everywhere causes audio gaps under concurrency because the codec window round-robins across requests (RFC #2568)." WAAV: confirms the per-stage decoupled-batch-size design; the codec micro-batch stage must NOT inherit the AR batch size.

**Async-chunk streaming:** `codec_chunk_frames=25`, `codec_left_context_frames=25` (overlap prevents audible boundary artifacts); `context_audio_samples = context_frames × hop_length`; first chunk can be larger for quality then smaller for latency. WAAV: the streaming-window archetype params.

**CUDA-graph constraints:** static buffers (KV fixed max-seq-len, pre-built causal masks + position tensors per step); `torch.argmax` not `torch.multinomial` (graph-safe — BUT sampling TTS needs multinomial → either sample outside the graph or use a graph-safe gumbel-argmax); fixed batch size with eager fallback; no dynamic control flow. 3–5× on the graphed component at fixed batch=1. WAAV: the lockstep step is fixed-shape by construction → graph-friendly; the sampler must be graph-safe or run outside the captured region.

**E2E test pitfalls:** one server-params set per test file (module-scoped fixture → restart races → `APIConnectionError`); no external URL fetches (inline base64 — CI can't reach raw.githubusercontent over TLS); use a `/health` readiness gate that returns non-200 until warmup completes (NOT `time.sleep`); warmup must gate readiness. WAAV: `/readyz` must gate on warmup+calibration complete, not just process-up (already in INFER_SPEC lifecycle — confirmed needed).

## B. vLLM-Omni diffusion-perf-opt + diffusion troubleshooting skills (host-stall + parity nuggets)

- **`torch.cuda.empty_cache()` = OOM-guard but a sync/idle stall.** FAILURE: per-call `empty_cache` in a hot path inserts a device sync → GPU idle bubble. MITIGATION: guard it by memory headroom / make it optional. WAAV: never call empty_cache in the per-frame loop; only on slot-free under memory pressure.
- **Cache scheduler coefficients/timesteps/masks when shape+steps fixed.** Lockstep + fixed NFE = everything is shape-stable → precompute the CFM/diffusion timestep schedule, causal masks, position tensors ONCE and reuse. WAAV: the step-bucket batcher precomputes the solver schedule per (model, NFE) at load.
- **CFG doubles the transformer forwards** → fold cond+uncond into the batch dim (×2); for multi-GPU, CFG-parallel vs larger-USP is a measured A/B. WAAV: confirms the CFG-×2 step-bucket batch; pass a seeded `generator` to the scheduler step or CFG-parallel diverges from sequential (non-determinism bug).
- **Measurement discipline (P0):** baseline latency MUST NOT run under torch-profiler (profiler distorts latency — "Command Buffer Full" is profiler overhead, not a real target); warmup excludes first-request lazy init; A/B one variable at a time; report in ms. WAAV: the calibration harness must measure WITHOUT profiler; first-request must be excluded (warmup gates readiness).
- **Quality gate mandatory for EVERY optimization, even math-preserving ones** (padding-trim, layout-cleanup, cache-reuse): exact/near-exact for math-preserving; SSIM/PSNR/LPIPS/cosine for approximate (quant/sparse/approx-attention). "Failed/inconclusive quality validation blocks ready-to-merge." WAAV: the accuracy gate applies to perf changes, not just quant.
- **Parity-vs-reference debug (the native-parity methodology, confirmed):** attention backend differs (FA vs SDPA → force SDPA to match reference), bf16-vs-fp32 on select ops, missing norm, scheduler rounding. Debug = step-by-step tensor compare vs reference, `num_inference_steps=2` small configs, transformer-isolation, binary-search the divergence. WAAV: this IS the onboarding parity bar — keep.
- **OOM fallback ladder (preference order):** enforce-eager (disable compile → saves compile memory) → cpu-offload → layerwise/block offload → (codec) slicing/tiling → reduce shape → TP. WAAV: the edge/low-VRAM tier needs eager-fallback + optional layerwise offload for big models; compile/CUDA-graph memory is real and must be budgeted.
- **`enforce_eager` is also an OOM escape, not just a debug flag** — CUDA-graph + compile capture cost real memory; must be a first-class config. WAAV: `enforce_eager` config knob (already implied by the batch-tiered kernels).

## C. The "real-world ready" rules distilled so far (cross-cutting, for the architecture revision)
1. Streaming MUST be delta (O(N) not O(N²)); test offline-concat == stream-concat byte-identical.
2. Per-step loops MUST be GPU-sync-free (no .item/.cpu/.tolist); test zero-D2H during decode.
3. Per-request/per-slot state MUST be keyed + freed; test concurrent crosstalk.
4. Per-stage batch sizes are independent (AR≥4, codec=1); a uniform default causes audio gaps under concurrency.
5. Validation = offline-parity + streaming-playback + concurrent-load (all three), not parity alone.
6. Readiness gates on warmup+calibration complete (first-request cliff), not process-up.
7. Codec/norms/RoPE/sampling-head stay high-precision; autocast corrupts codec audio.
8. Quality/accuracy gate applies to EVERY perf+quant change, with a streaming+concurrent layer.

## F. Moshi/moshi-server LOCKSTEP correctness traps (agent-mined, EXHAUSTIVE — the scheduler spec)
The central law: **MASKED ≠ ABSENT.** Idle/desync slots stay in the fixed batch; the dense kernel reads/writes every row. Almost every trap = "make the masked row's data harmless, never skip it."

**F1 [CRITICAL] Masked rows need a SUBSTITUTED valid input token before the forward.** `is_init |= ~exec_mask` (`lm.py:698-702`): masked-or-still-warming rows are forced to the `initial`/BOS token via `torch.where(is_init, initial, gathered)` BEFORE embedding, else the KV-gather reads sentinel `-2`/stale → CUDA illegal-memory/NaN that kills the WHOLE batch (all 64 users). WAAV: pre-kernel input-substitution is a hard rule; test = a batch with idle slots produces identical output for active slots as if idle slots were absent.

**F2 [CRITICAL] Gate EVERY per-stream mutation through `where(exec_mask,new,old)`.** offset (`lm.py:759`), KV scatter (`scatter_with_mask_` `lm.py:31-37`), KV end-offset (`transformer.py:278`), MHA/layer offsets, conv ring `previous` (`conv.py:264`), `first`-frame flag (`conv.py:269`), sampler RNG offset, partial-word buffers. A SINGLE ungated mutation = silent corruption that only appears when a stream idles-then-resumes (RoPE phase jump / poisoned ring cells) — invisible in single-stream tests, breaks under multi-tenant load. WAAV: enumerate every mutable per-slot tensor; assert each updates through ONE masked-select; test = idle-then-resume a slot, assert byte-identical state + transcript vs never-idled.

**F3 [CRITICAL] Transactional slot recycling (`reset_batch_idx`).** Slot 7 user disconnects → new user admitted into slot 7 → without reset, new user's attention sees old user's KV + word buffer = cross-user transcript contamination (PRIVACY disaster). Mitigation: ONE `reset_slot(i)` fanning out to KV pointers + conv rings + sampler + word buffers + offset + host state (`asr.rs:256-264` resets lm + audio_tokenizer + item-state). Note: does NOT wipe KV bytes — relies on `positions/indices=0` + mask making stale bytes unreachable (correctness depends on the mask). Monotonic `channel_id` drops any output/marker whose id ≠ live occupant (`batched_asr.rs:92-100`). WAAV: one transactional reset_slot; channel-id guard; test = fresh stream in recycled slot byte-identical to never-used slot.

**F4 [HIGH] Ring-KV logical-position masking on wraparound.** Fixed `(B,H,context,D)` alloc; write at `(offset+delay)%context`. Once offset>context, physical slot order ≠ time order → naive causal mask `j≤i` attends to FUTURE tokens in recycled slots. Mitigation: reconstruct per-cell logical position, mask by `pos<=my_pos` (causal) AND window AND never-written⇒-1 (`kv_cache.rs:121-151`). Bake Kyutai test vectors (`kv_cache.rs:260-327`: pre-wrap/exact-fill/post-wrap/mixed-mask). WAAV: store logical pos per cell; the published test vectors become unit tests.

**F5 [HIGH] Future-step marker/flush protocol.** "Stream done" fires at `now + asr_delay_in_tokens + buffered_frames` via a step-ordered `BinaryHeap<Marker>` (`batched_asr.rs:314-326,422-433`); else you echo "done" before the delayed model emits the last words → truncated transcript. One-shot/POST path: append real audio + marker + **10s of trailing silence** (`vec![0f32;240000]`) to flush the delay pipeline, terminate on the marker NOT input-exhaustion (`batched_asr.rs:550-563`). Per-stream lifecycle ACTIVE→MARKER_RECEIVED→IS_EOS; free slot only after offset≥real_end, NEVER on disconnect alone (tail still draining). WAAV: model the 3-state lifecycle; pad+marker for non-streaming-over-streaming-core; test = transcript not truncated at clip end.

**F6 [HIGH] All-idle path + warm-up.** Always apply admissions/resets/control-plane FIRST, then compute exec_mask, then run kernel ONLY if `exec_mask.any()` else short-sleep 1-2ms (never busy-spin, never run kernel on all-False batch — `batched_asr.rs:236-273`). Warm-up 2-3 steps with full mask + `synchronize()` at startup → fills conv/KV boundary state + forces CUDA-graph capture OFF the hot path (else first request pays seconds of capture). WAAV: two-phase outer loop; warmup gates readiness (ties to C7).

**F7 [HIGH] CUDA-graph: lockstep GUARANTEES static shapes → one graph lasts forever.** B, T=1, cache shapes constant for server lifetime BECAUSE idle slots are masked-not-removed (drop them → B changes → re-capture every frame = catastrophic). Replay guard `_match_values_copy_tensors` (`compile.py:232-259`): shape-change → HARD ERROR ("same shapes ... NO_CUDA_GRAPH=1"), scalar-change → error → converts silent-stale-graph-corruption into a loud crash. Escapes: `NO_CUDA_GRAPH`/`NO_TORCH_COMPILE` env, disable on non-CUDA by default. WAAV: wrap graphed callables with shape+scalar-identity assert; first-class disable env; this RESOLVES critique C2/C8 (sample outside graph; eager escape).

**F8 [HIGH] Acoustic-delay per-codebook ring + off-by-one.** Cache depth = `max_delay+2` (the +2 = off-by-one guard so max-delay write & oldest read don't collide). Write `(offset+delays[k])%CT`, read `(offset-max_delay+gen_delays[k])%CT`. Before `step<acoustic_delay`, codebooks≥1 teacher-forced to PAD (`pre_delay_tokens`) — no real acoustic token exists yet. WAAV: per-codebook delay ring sized max_delay+2; pad-force the warm-up window; test the delay write/read alignment.

**F9 [MED] Slot-leak-on-disconnect (layered defense).** Free slot from INSIDE the step loop on ANY of {receiver closed, sender disconnected, send error, ping-timeout 20s, idle-timeout 120s} (`batched_asr.rs:301-360,393-426,597-635`) — don't rely solely on a disconnect callback (can be missed). Open-slots gauge + per-conn step counter for leak detection. Ping every 10s. WAAV: multi-trigger slot-free; used/total_slots gauge = autoscale signal.

**F10 [MED] RTF<1 budget + backpressure.** Meter per-step wall time vs frame budget (`MODEL_STEP_DURATION`); NO built-in frame-drop — audio buffers in per-stream VecDeque, relies on avg RTF<1 + autoscale. WS `write_buffer_size(0)` on every streaming route → flush per frame (default coalescing adds 10s-of-ms jitter to an 80ms budget). WAAV: per-step-wall-time + per-stream-buffer-depth as first-class metrics; EXPLICIT overrun policy (buffer+autoscale vs frame-drop — not free); disable WS write-coalescing.

## G. SGLang-Omni STAGE/RELAY/SCHEDULER scars (agent-mined — the stage-DAG + relay + admission spec)

**G1 [CRITICAL] Prefix-cache/KV key MUST fingerprint injected conditioning, not just token ids.** Voice-clone TTS pastes ref-audio embeds at `-100` PLACEHOLDER positions → token-ids identical across requests → RadixAttention concludes prefixes match → cross-contaminates KV between different ref-audios = silent WRONG-VOICE output (no crash, only under concurrency). Fix: `Req.extra_key = blake2b(full N-codebook ref sequence, 2 bytes/value)` (`request_builders.py:47-99`) — hash over ALL codebooks (cb0-only collides); zero-shot (no ref) → `extra_key=None` so legit prefix-sharing survives. WAAV: any KV-reuse/prefix key includes a content hash of injected conditioning (ref-audio/speaker/image) over every channel; `None`-escape for genuinely-identical prefixes. Test = two reqs, same text, different ref-audio → different voice out (not contaminated).

**G2 [CRITICAL] End-of-stream is an EXPLICIT FINAL frame, never inferred from silence; cancelled ≠ completed.** A consumer inferring "done" from absence-of-chunks can't tell done from stalled-producer → premature close or hang. `DataReadyMessage.is_done`/`error` sentinel; `StreamQueue.put_done` → `get()` returns None on sentinel; protocol rule: "absent sentinel + premature close = the client-side FAILURE signal" (`refactor_rfc.md:276`). WAAV: streaming egress sends explicit FINAL; "closed without FINAL" = failure; barge-in cancel must be DISTINGUISHABLE from completion (ties to barge-in-cancels-LLM). Test = cancelled stream and completed stream produce different terminal frames.

**G3 [HIGH] Never busy-spin a scheduler loop (the GIL-starvation→Rust translation).** Python: busy AR loop pinned the GIL → co-located encoder forward slowed ~600× (audio QPS >10→<0.5); fix = `time.sleep(0.001)` on the IDLE branch only (`omni_scheduler.py:919`). Rust has no GIL but the hazard reappears as CPU-core/runtime starvation: `loop { try_recv() }` starves co-located stages. WAAV: block on `crossbeam recv_timeout`/`tokio Notify` when idle, hog the core only when busy (matches Moshi F6 2ms-sleep). Deeper lesson: SGLang moved to ENCODER DISAGGREGATION (separate process) because colocated encoders interfere — prefer stage=process for the hot AR vs encoder; colocation is an optimization that MUST be starvation-load-tested.

**G4 [HIGH] Relay credit flow-control + notify-before-wait (deadlock).** Bounded credit pool (default credits=2) = back-pressure: 3rd in-flight `put` blocks until a receiver releases → naturally throttles fast-producer/slow-consumer; without it → pool overflow/OOM. NIXL deadlock: must send data-ready CONTROL message BEFORE awaiting transfer completion on any pull/RDMA transport (receiver-initiates-read) — wait-then-notify deadlocks (`relay_io.py:437`). Double-release should be a HARD error (not a swallowed log). shm = receiver-owns-unlink → orphan leak if receiver crashes → needs a reaper. WAAV: credit back-pressure on the sidecar↔stage relay; notify-before-wait as a tested per-transport property; orphan-reaper for shm.

**G5 [HIGH] Same-process = MOVE OWNERSHIP, never serialize; fan-out by reference is an aliasing bug.** Same-OS-process hop passes Python object by reference (zero copy) but fan-out (1 result→N stages) by reference → mutation in one corrupts others; guarded by `_is_isolated_projected_payload` (id()-graph walk ensuring distinct mutable containers).
